# essentia-env

Essentia Environments website (Vite + React).

```bash
npm install
npm run dev
```

Copy `.env.example` to `.env` for the chatbot. Contact, career, and Instagram already use the live Vercel API.

Large videos, PDFs, and sales-kit images are not in git (too big for GitHub). They stay in local `public/` and on the live site.
